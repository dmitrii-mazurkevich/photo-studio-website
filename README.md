# Photo studio site

A photographer's site that stays fast with heavy images: gallery, lightbox, before and after slider.

**Live:** https://dmitrii-mazurkevich.github.io/photo-studio-website/

![Photo studio site](preview.png)

## Built with

HTML, CSS, JavaScript, lazy loading. Static site without a build step: open `index.html` or publish the folder to any hosting.
English and Russian versions with a language switcher, layout for phones and desktops.
